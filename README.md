# DesignsWorkLife

High-fidelity front-end clone of the [DesignRush](https://www.designrush.com/) B2B agency directory / marketplace / awards / news product surface.

## Stack

- Vite + React + TypeScript
- React Router
- Static demo data (no backend)

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Preview

GitHub Pages: `https://pwusojh610430-cmyk.github.io/designsworklife/`

## Pages

- `/` Home
- `/agency` Directory + category listings
- `/agency/profile/:slug` Agency profile
- `/best-designs` Awards gallery
- `/best-designs/how-it-works` Judging rules
- `/news` + article detail
- `/marketplace/project-brief` Brand brief form
- `/marketplace/membership` Agency pricing
- `/benefits` `/about-us` `/methodology` `/contact-us` `/account/login`
